# pong (and snake)

A simple Pong game in a single HTML file. You control the right paddle with your mouse or the arrow keys. Click or press Space to start. Press T (or use the Theme button) to switch between black/green and white/blue.

## Run locally
Open `index.html` in a browser.

## Deploy
Connected to Vercel. Every push to `main` updates the live site.

## Snake
Click the "Play Snake" button (top right) to switch games. Arrow keys or WASD to steer, Space or click to start. Snake is always black with an orange snake.
